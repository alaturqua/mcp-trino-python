# Security Policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report it privately through GitHub: go to the repository's **Security** tab and click
**Report a vulnerability** ([direct link](https://github.com/alaturqua/mcp-trino-python/security/advisories/new)).

Include the affected version, steps to reproduce, and the impact. You should get a reply within 7 days.
Once a fix is released, the advisory is published and you are credited unless you prefer not to be.
